# INDLOOK HTML Website

A responsive HTML/CSS/JavaScript recreation of the blue-and-white INDLOOK design supplied by the user.

## Contents
- `index.html` - website structure and content
- `style.css` - responsive layout and styling
- `script.js` - mobile navigation toggle
- `assets/` - image crops taken from the supplied design reference

## Open locally
Extract the ZIP and open `index.html` in a browser. For best results, keep the `assets` folder beside the HTML file.

## Publish safely
Upload the contents to a NEW GitHub repository such as `Indlook-Web`, then deploy that repository in Roar AI. Do not overwrite or modify the existing Android repository `Muralpaint12/Indlook-`.

## Functionality
This package is a visual frontend. Login, real posts, media uploads, messaging, calls, notifications, and marketplace data are not connected yet. These require secure backend/API integration with the existing INDLOOK services. Text, statistics, and testimonials shown here are design/sample content, not verified live metrics or user data.
